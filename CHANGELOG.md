# Changelog

## 0.2.0

- Replaced the Rust, FFI, protobuf, code generation, and nested-package layout
  with one pure-Dart Flutter package.
- Added the embedded authenticated HTTP server, dashboard, REST tools, MCP
  2026-07-28 support, and legacy 2025 Streamable HTTP sessions.
- Added bounded DevTools views, observability, UI automation, app adapters,
  runtime controls, file tools, telemetry, discovery, and optional VM service
  tools.
- Added release blocking, feature gates, strict schemas, result limits,
  lifecycle cleanup, and security documentation.
